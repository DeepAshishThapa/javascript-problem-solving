1. What is formatting in html?
Formatting means using special tags to change the appearance of the text on web page. We can use bold, italic, underline, strong,
etc.

2. Tell me the difference bwtween bold and strong?
Bold and strong are both used to hightlight the text in web page. But the difference is seen in screen reader. The text
highlighted by bold is usually expressed and pronounciated in same tone while for strong its expressed in different tone
which are usually used to provide meaning to text or words like warning, or emergency.

3. What is the use of required attribute in element?
Required attribute is used when we want the use to fillup the element compulsorily. Like in input element we use required 
attribute when we want to fill up forms for email, password.

4. What are empty tags?
The tags which donot require the closing tag like <br> <img> <hr>.

5. Whats the difference in <div> and <span>?
<div> is a block element which means it covers the whole width 100% when used while span is inline element and takes the width
only required by it.

6. what is the difference between display none and visibiluty.
Display none completely erases the element from the ui and it wont cover any width and height. Visibility makes the element 
100% transparent but the element will still hold physical attribues and cover height and width.

7. What is specificity in css?
specificity is a set of rules browser uses to determine which css property values are most relevant to an element. If an 
element has two conflicting css selectors then browser calculates specificity for both and the higher one gets applied.

8. How do you use gradients in css?
We use gradients by using background property in css. There are three gradients linear, radical and conical and we can pas
two or more colors for styling.

9. Differentiate between flexbox and grid?
flex box is 1d and grid is 2d which are used to align elemennts. But flex box is 1d and aligs in row or column but not both
at the same time. While grid can aligh elements in row and column at the same time.
